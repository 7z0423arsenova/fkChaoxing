创建自己的配置

留空时读取启动目录中的 config.ini。账号和题库设置均从配置文件读取。

已有配置文件可以用上方“选择文件”直接打开。新用户填写账号与密码；题库可以稍后再设置。保存后就能读取课程。

Cookie 可用时直接登录；失效后仍需要账号和密码。

留空也可以。读取课程后仍能在左侧列表中选择要学习的课程。

学习设置

取消勾选后跳过答题，继续处理视频等任务。启用答题需要配置题库；是否自动提交由下方选项控制。

视频等任务进行时，提前让题库或 AI 查询后续章节检测答案。可缩短等待时间，但会提前消耗题库/AI 请求次数。

需要本机安装 Python 与 ddddocr（python -m pip install ddddocr）。开启后遇到学习通反爬验证码会自动识别并重试原请求。

题库设置（可选）

AI 参数由你填写；如果填写服务商预设（如 ollama、lmstudio），API 地址可以留空。

默认只保存找到的答案。启用后，题库覆盖率不低于下方比例才会提交；请自行确认题库的准确率。

题库覆盖率低于该值时只保存答案，不提交。默认 0.8。

账号、密码和 API Key 会写入本机用户数据目录的 config.ini。
